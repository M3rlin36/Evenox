## Méthode de rattachement

Une occurrence est classée dans la première forme qui la contient, dans cet ordre :

1. URL `fonts.googleapis.com` (ex. `…/css2?family=Luckiest+Guy&…`) ;
2. attribut Divi `inline_fonts="…"` ;
3. déclaration de la variable CSS `--font-display: 'Luckiest Guy', cursive;` ;
4. attribut `style="…"` porté par un `<span>` ;
5. déclaration `font-family: 'Luckiest Guy', …` (bloc `<style>` ou attribut `style` d'une autre balise).

Une occurrence qui tomberait hors de ces cinq cas serait notée `bloc <style> (autre)` ou `autre` ;
le tableau de répartition ci-dessus montre si ce cas s'est présenté.
