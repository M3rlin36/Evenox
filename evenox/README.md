# Evenox — CTA calculateurs

Correctif pour les catalogues qui affichent **Monte ton forfait**.

Aujourd’hui le bouton « Monter mon forfait » envoie presque partout vers le
calculateur tables et chaises. Ce dossier livre un petit plugin WordPress qui
pointe chaque page vers le calculateur de sa catégorie (21 catalogues live).

- Jeux géants / intérieur / table → [location-jeux-geants](https://evenox.ca/location-jeux-geants/#configurateur)
- Gonflables → [location-jeux-gonflables](https://evenox.ca/location-jeux-gonflables/#configurateur)
- Friandises → [machines-gourmandises](https://evenox.ca/machines-gourmandises/#configurateur)
- Murs / décor → [location-decoration-evenementielle](https://evenox.ca/location-decoration-evenementielle/#configurateur)
- Autres catalogues → voir `INSTALL.md`

Les calculateurs Divi restent sur leurs landings. On ne les recopie pas dans
chaque catalogue. Seule `/decoration/` a déjà le widget sur la page.

Rien n’est publié tant que le zip n’est pas activé sur WordPress.
