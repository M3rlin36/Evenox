# Evenox — CTA calculateurs

Correctif pour les catalogues qui affichent **Monte ton forfait**.

Aujourd’hui le bouton « Monter mon forfait » envoie presque partout vers le
calculateur tables et chaises. Ce dossier livre un petit plugin WordPress qui
pointe chaque page vers le calculateur de sa catégorie.

- Jeux géants → [location-jeux-geants](https://evenox.ca/location-jeux-geants/#configurateur)
- Gonflables → [location-jeux-gonflables](https://evenox.ca/location-jeux-gonflables/#configurateur)
- Autres catalogues → voir `INSTALL.md`

Rien n’est publié tant que le zip n’est pas activé sur WordPress.
