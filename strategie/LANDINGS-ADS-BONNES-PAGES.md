## Pages à corriger avant d’y envoyer du $ Ads

1. **`/forfaits-tables-chaises/`** — ajouter bouton hero « Réserver / Voir les 3 forfaits ».  
2. **`/forfaits-fete-enfants/`** — renforcer CTA hero (score CTA bas).  
3. **Pages ville chaises** — hero doit vendre forfait Express/livré, pas seulement 3 $/chaise.  
4. **Créer `/express-72h/`** — landing Ads dédiée (cash + QS).  
5. Aligner CTA « Réserver » → dépôt Booqable **ou** assumer lead `/contact/` dans le tracking.

## Ce qu’on n’utilise pas (et pourquoi)

| URL type | Raison |
| --- | --- |
| `/product/jeu-gonflable-…` | SKU ; faible intent « forfait » ; QS moyen |
| Blogs `/combien-coute-…` | Info, pas conversion Ads |
| `/contact/` comme seule destination | Pas de preuve prix / offre |
| `/lot-de-100-chaises-…` | Panier flou pour Search froid |
| Mariage pages multiples | Cycle long ; phase 2 relation/partenaires |
