## 1. Google Ads (Search) — levier #1 « intention d’achat »

### Ce que disent les vidéos
- Les gens qui tapent « bounce house rental near me » / « location jeux gonflables Laval » sont **prêts à booker**.
- Tu ne paies **que si quelqu’un clique**.
- Radius de livraison (pas « tout le Québec ») : typiquement **25–50 miles / ~40–80 km**, chez Évenox reste sur Rive-Nord / Laval / Montréal nord.
- Envoie vers la **page produit/offre**, pas seulement l’accueil.
- Juge sur **90 jours**, pas 7 jours (algorithme + Smart Bidding).

### Mise en application Évenox (semaine 1)

**A. Compte**
1. Google Ads → compte lié à `evenox.ca` + suivi conversions (appel + formulaire + début réservation Booqable).
2. Conversion tracking : appel téléphone, envoi soumission, clic « Réserver ».

**B. Campagnes (3 max au début)**

| Campagne | Mots-clés exemples | Landing |
| --- | --- | --- |
| Express 72h | location tables chaises Laval, location chaises Sainte-Thérèse urgent | page Express |
| Jeux | location jeux gonflables Rive-Nord, château gonflable Laval | page jeux |
| Photobooth / corpo | location photobooth corporatif Montréal, photobooth Laval | page photobooth |

**C. Réglages (comme dans les tutos party rental)**
- Localisation : **rayon autour de Sainte-Thérèse / Mirabel**, pas la province entière.
- Langue : français (+ anglais si tu livres bilingue).
- Négatifs : `acheter`, `vente`, `usagé`, `DIY`, villes hors zone (Longueuil si tu ne veux pas, etc.).
- Extensions : appel `514-559-1893`, liens annexes (Express, Jeux, Soumission), lieu.

**D. Budget**
- Départ : **20–40 $/jour** en saison (≈ 600–1 200 $/mois).
- Couper ce qui ne booke pas après 2 semaines de données ; monter ce qui booke.

**E. Annonce type (structure Event Hawk)**
- Titre : bénéfice + ville (`Location jeux gonflables Laval`)
- Titre 2 : preuve (`Livraison + installation clé en main`)
- Titre 3 : offre (`Réservation en ligne 24/7`)
- Description : prix visibles / Express 72h / note Google

**F. Suivi hebdo**
- Coût / lead, coût / booking, taux de réponse &lt; 1 h (Event Hawk insiste : lead froid = lead mort).

## 2. Google Business Profile + avis — gratuit, amplifie les Ads

### Ce que disent les vidéos / guides
- Map Pack = souvent **le** canal local #1 en ROI.
- Photos + avis récents = ranking + confiance.
- SMS post-événement pour demander l’avis (automation Event Hawk).

### Mise en application
1. Fiche Google complète : catégories (location matériel événementiel / jeux), zone de service, horaires réels, site, téléphone WhatsApp.
2. **2–3 photos / semaine** : montage, camion, Express, jeux installés.
3. Après chaque événement (J+1) : SMS  
   `Merci pour votre confiance ! 30 secondes pour un avis Google : [lien]`
4. Répondre à **tous** les avis &lt; 24 h.
5. Objectif 90 jours : **52 → 100+ avis**.

Ça baisse ton CPA Ads (meilleur Quality Score / meilleur taux de conversion).

## 3. Site / conversion — « ne paie pas des clics pour une page qui fuit »

### Ce que disent les vidéos (Event Hawk, Party Rental Toolkit)
- Une intention **par page**.
- Mobile first.
- Prix / dispo / CTA évidents.
- Remonter le lead en **SMS &lt; 60 secondes** quand possible.
- Pop-up / capture = OK si pas agressif.

### Mise en application Évenox
1. Chaque Ads → page dédiée (Express / jeux / photobooth) avec **1 bouton** : Réserver ou Obtenir mon prix.
2. Au-dessus de la ligne de flottaison : prix ou fourchette, zone, délai de réponse.
3. Preuve sociale : note 4,8★ + 2–3 avis courts.
4. Si lead formulaire : SMS ou appel **le jour même** (idéalement &lt; 15–60 min).
5. Booqable : panier simple, dépôt clair, pas 10 étapes.

## 4. Meta Ads (Facebook / Instagram) — awareness + retargeting

### Ce que disent les vidéos
- Intent **plus bas** que Google Search.
- Utile pour : parents (jeux), mariages (inspiration), **retarget** ceux qui ont visité le site.
- Creative = photos/vidéos de vrais montages (15–30 s).
- The Smart Hustle : « free advertising » = groupes / organique ≠ boost aveugle.
- The Rental Journey : **groupes Facebook mariages** = poster du contenu utile (pas spam).

### Mise en application
**Phase A — organique / groupes (0 $)**
- 3 posts / semaine (timelapse, avant/après) — déjà dans ton guide de marque.
- 5–10 groupes locaux (Rive-Nord, Laval, mariages QC) : 1 post utile / semaine max, règles du groupe respectées.

**Phase B — Ads petits budgets (10–20 $/jour)**
1. Campagne trafic ou leads : parents 25–45 ans, rayon livraison.
2. Créas : carousel inventaire + « prix dès X $ » + CTA.
3. **Retargeting** (prioritaire) : visiteurs site 30 jours → offre Express ou « soumission en 24 h ».

Ne mets pas le gros du budget Meta tant que Google Search n’est pas rentable.

## 5. Programme de références clients (ERS)

### Ce que dit la vidéo ERS
- Owners négligent ça pendant qu’ils font des Ads.
- Méthode Rob : **3 cartes** par client (ni 1, ni 10).
- Code promo = prénom du client (`TOMMY`).
- Récompense après 2–3 referrals (ex. machine à neige gratuite / crédit).

### Mise en application Évenox
1. À la livraison / ramassage : carte ou message  
   `Code ALEXANDRE = 10 % pour ton ami · toi = 25 $ de crédit après 2 réservations référées`
2. Dans Booqable / Notion : champ « code référent ».
3. Automatiser J+1 avec l’avis Google : même SMS, 2 liens (avis + « réfère un ami »).
4. Afficher le programme sur la page confirmation.

Coût ≈ 0 $ jusqu’à ce que ça booke ; ROI souvent meilleur que Meta awareness.

## 6. Partenaires lieux / planners / écoles — preferred vendor

### Ce que disent Venue RX + Andrea Eppolito
- Preferred list = beaucoup de business **une fois dedans**.
- **Ne pas** : cold email générique, Zoom non sollicité, « je te donne 10 % » en premier (surtout planners luxe).
- **Faire** : questions, valeur d’abord, relation, connaître leur clientèle, être invité sur la liste.
- The Rental Journey : appeler planners avec **perks / 10 %** = test — marche mieux avec **traiteurs / salles / écoles** qu’avec planners luxe.

### Mise en application Évenox (adapté QC / ton stock)

**Cibles prioritaires (pas luxury Vegas)**
1. Écoles / camps / CPE Rive-Nord  
2. Salles de réception / centres communautaires / clubs de golf  
3. Traiteurs locaux  
4. Photographes / DJ (échange de leads)  
5. Planificateurs volume (pas luxe) si tu as le look

**Script 4 semaines (Venue RX adapté)**

| Semaine | Action |
| --- | --- |
| 1 | Liste 30 noms + Instagram/site. Identifier le décideur. |
| 2 | Commentaire / story utile, ou passage après un événement chez eux. Demander *leurs* pains (livraison, urgence, kids). |
| 3 | Offrir de la valeur : « kit urgence Express pour vos clients », photos de montages dans leur type de salle, assurance + fiche PDF. |
| 4 | Proposition soft : « On peut être votre option mobilier/jeux recommandée — réponse &lt; 2 h, on complète si stock plein. » Commission **seulement** si le partenaire le demande / modèle traiteur-école. |

**Kit partenaire (1 page PDF)**
- Zone + délais  
- Top 10 items + Express 72h  
- Assurance  
- Contact prioritaire  
- Option : code partenaire / 10 % (écoles, traiteurs)  

**Règle Andrea pour planners « premium »** : relation et qualité d’abord ; la commission en ouverture tue la crédibilité.

## Résumé ultra-court

1. **Google Ads** = filet pour gens qui cherchent **maintenant**.  
2. **Avis / GBP** = confiance + Map Pack.  
3. **Pages qui convertissent** = ne pas brûler le budget.  
4. **Meta** = chauffer + retarget, pas le moteur principal.  
5. **Referral clients** = Ads gratuites via tes clients satisfaits.  
6. **Partenaires** = liste preferred, relation d’abord, cash ensuite.
